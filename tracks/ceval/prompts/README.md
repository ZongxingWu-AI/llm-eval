# C-Eval Prompt 模板目录

## 1. 目录用途

本目录保存 C-Eval 客观题使用的 Markdown Prompt 模板。代码负责加载模板并填入题干、选项等变量，模板文件本身不保存模型回答。

## 2. 数据来源

输入来自 `tracks/ceval/data/` 中的一道题目字典。

## 3. 文件命名规则

模板使用描述用途的 `.md` 文件名，例如 `ceval_prompt.md`。

## 4. Prompt 文件说明

模板通常包含以下占位内容：

| 内容 | 含义 |
|---|---|
| `question` | 当前题目的题干。 |
| `A`、`B`、`C`、`D` | 四个选项。 |
| 输出要求 | 要求模型返回一个选项字母，便于后续解析。 |

## 5. 输入和输出

输入：一条 C-Eval 题目字典。

输出：发送给模型的完整 Prompt 字符串。

示例输入：

```json
{"question":"1+1等于几？","A":"1","B":"2","C":"3","D":"4"}
```

示例期望输出格式：

```text
B
```

## 6. 上游和下游

`tracks.ceval.evaluate.build_prompt()` 读取模板，`extract_answer()` 再解析模型返回的选项字母。

## 7. 是否提交 Git

Prompt 模板属于代码配置，应提交 Git。修改模板后应重新运行 C-Eval 测试。
