# 测评了那么多 AI 才醒悟：不会写 Prompt，测了也白测

---

过去这段时间，我集中测评了一圈市面上的主流 AI——写文案的、画图的、生成视频的，几乎都试了个遍。

一开始，我的测评方法简单粗暴：同一个任务、同一段提示词，同时丢给几个模型，谁效果好谁就赢。

我当时的判断标准也很清晰，就看三件事：

1. 模型听不听得懂我的 Prompt；
2. 同样的 Prompt，谁的输出更合我心意；
3. 效果相近时，谁的发挥更稳定、更划算。

但测着测着，我发现了一个扎心的事实：

很多时候，拉开差距的根本不是模型，而是我写的那段 Prompt。

一段随手写的提示词，可能刚好踩中 A 模型的强项，却精准踩中 B 模型的弱项。同一张"考卷"，对不同考生来说，难度天差地别。

换句话说——

**不会写 Prompt，测出来的结论很可能是不公平的，甚至是错的。**

所以今天这篇，先不聊测评结果。我们先把基本功补上：**Prompt 到底该怎么写？**

想让 AI 完美听懂你的话，核心就两点：**结构化思维**，以及**提供符合模型底层逻辑的信息维度**。

而且文生文、文生图、文生视频，这三类模型的训练数据和生成逻辑完全不同，Prompt 的写法也有本质区别。接下来，以我最近学习的经验，讲解下如何从"拼运气"进阶到"精准控制"。

## 三条通用底层原则

为什么模型会误解你？

进入具体场景前，必须先理解一个本质：**模型没有人类的"常识直觉"，它只有"概率关联"。**

下面这三条原则，既是写 Prompt 的基本功，也是我后来做测评时的"公平性底线"。

### 1）精准替代模糊

**别这样写：**

> "请写一篇字数适中的文章。"（"适中"是多少字？）

**改成：**

> "请写一篇 800 到 1000 字的文章。"

**别这样写：**

> "画一个好看的背景。"

**改成：**

> "画一个赛博朋克风格、霓虹灯闪烁、雨后湿漉漉的东京街头背景。"

### 2）正面指令替代负面限制

模型对"不""别""无"这类否定词的注意力权重很低。你写"不要出现红色"，它反而会高度关注"红色"这个词。

正确的姿势是：告诉它"要做什么"，而不是"不要做什么"。把"不要出现红色"，换成"只使用蓝色和绿色调"。

### 3）结构化呈现，善用分隔符

用 **###**、**"""** 或 XML 标签（如 `<context></context>`），把"背景""任务""限制条件""输入数据"隔开。

这能帮模型的注意力机制精准分配权重——哪段是资料，哪段是指令，一眼分清。

## 文生文：逻辑、约束与角色扮演

**CO-STAR 框架 + 两个进阶技巧**

文生文模型（如 GPT、Claude）的强项，是语义理解和逻辑推理。想让它们写出符合预期的文章、代码或方案，最经典的构建框架是 **CO-STAR**：

- **C（Context）背景**：交代任务的来龙去脉或当前现状
- **O（Objective）目标**：明确要完成的具体任务
- **S（Style）风格**：专业、幽默、通俗易懂、学术……
- **T（Tone）语气**：同理心、严肃、鼓舞人心……
- **A（Audience）受众**：5 岁小孩、行业专家、潜在客户……
- **R（Response）输出格式**：Markdown、表格、JSON、分点列表……

在这个框架之上，还有两个进阶技巧：

- **思维链（Chain of Thought，CoT）**：涉及复杂推理或计算时，在结尾加一句"请一步一步思考，写出推理过程，最后再给出答案"，能大幅降低模型的幻觉和逻辑错误。
- **少样本提示（Few-Shot）**：解释一百遍"什么是高情商回复"，不如直接给它两组"原句 vs 润色后"的对照示例。

来看一组直观的对比。

**糟糕的写法：**

> 帮我写一封拒绝客户退款的邮件，语气要委婉。

**精准的写法 · 可直接复制：**

> **### 背景** 客户购买了我们的线上课程，已观看超过 80% 的内容，现以"不符合预期"为由申请全额退款。根据用户协议，观看进度超过 50% 不予退款。
>
> **### 任务** 撰写一封拒绝退款的申诉回复邮件。
>
> **### 语气与风格** 态度真诚、委婉但立场坚定。避免生硬的法条字眼，多强调我们付出的版权成本和技术支持，并提供折中方案（赠送一张 50 元无门槛课程优惠券）。
>
> **### 读者** 一位有些情绪化、觉得钱花得不值的普通消费者。
>
> **### 输出格式** 请严格按以下结构输出：1. 礼貌问候与同理心倾听 2. 委婉说明无法退款的原因（结合已观看 80% 的事实）3. 给出折中方案（优惠券）4. 祝好与落款

同一个模型，输入从一句话换成这段结构化 Prompt，输出质量完全是两个档次。

反过来说，测评时如果你给 A 模型一句话、给 B 模型结构化提示——**那这场比赛从一开始就谈不上公平。**

## 文生图：视觉元素、构图与渲染控制

**把自己当成"摄影指导 + 画师"**

和文生文相反，文生图模型（如 Midjourney、Stable Diffusion、**即梦AI**）**不具备逻辑推理能力**，它们是靠"标签（Tokens）"去匹配噪声画布的。

所以写文生图的 Prompt，你要把脑回路切换成"摄影指导 + 画师"。先记住这个黄金公式：

> 主体 + 环境背景 + 构图镜头 + 灯光 + 材质画风 + 渲染参数

- **主体**：细节越具体越好。别写"一只猫"，写"一只金黄色的英短猫，睁大绿色的眼睛，毛发蓬松"
- **环境**：时间、地点、天气。如黄昏、雨后的石板路、背景虚化的霓虹灯
- **构图与镜头**：特写（Close-up）、全景（Wide shot）、鸟瞰（Bird's eye view）、黄金分割构图（Rule of thirds）、大光圈虚化（f/1.8 depth of field）
- **灯光**：丁达尔效应（Tyndall effect）、逆光（Backlighting）、柔光（Soft lighting）、赛博朋克霓虹光（Neon lighting）
- **画风与材质**：3D 渲染（Octane Render）、写实摄影（Photorealistic）、吉卜力动漫风（Ghibli style）、水彩画（Watercolor）

还有一个我在测评文生图模型时最常踩的坑：**用写文的逻辑去写图**。

**错误写法：**

> "一个男孩因为考试没及格而感到非常伤心，正坐在雨中哭泣。"

模型理解不了"因为考试没及格"这种因果关系。把它翻译成纯视觉语言：

**正确写法：**

> "一个 10 岁的亚洲男孩坐在倾盆大雨中的公园长椅上，低着头，脸上混合着雨水与泪水，手里紧握着一张写着红色'10分'的试卷，情绪沮丧，特写镜头，情绪化写实摄影。"

看到区别了吗？**因果要藏在道具和表情里，而不是写在句子里。**

最后看一个示例：

> **示例 PROMPT：**
>
> 一只威严的白鹿，带着发光的绿松石色鹿角，站在薄雾缭绕的古老森林中，金色阳光穿透浓密的树冠，超写实、电影级光影、8K 分辨率、85mm 镜头拍摄、f/1.4 浅景深。

## 文生视频：动态、分镜与时间控制

**像导演一样思考**

文生视频模型（如 Sora、Runway、**Seedance 2.0**）比文生图多了一个至关重要的维度：**时间与运动**。

写视频 Prompt 的关键在于：你要像**导演和摄像师**一样思考，不仅描述"画面里有什么"，还要描述"画面如何动起来"。黄金公式同样先奉上：

> 静态起幅（首帧画面）+ 主体动作 + 相机运动 + 环境与光影变化

- **静态起幅**：类似文生图，先勾勒出第一帧的画面
- **主体动作（核心）**：描述人或物如何运动。避免"充满动感"这类抽象词，用具体动作词：奔跑、飘动、融化、爆炸、缓缓转头
- **相机运动（灵魂）**：运镜是视频的灵魂，请直接使用专业电影术语——推／拉（Zoom in / Zoom out）、横移（Pan left / Pan right）、俯仰（Tilt up / Tilt down）、跟拍（Tracking shot）、无人机航拍（Drone shot）
- **环境与光影变化**：视频是动态的，光影也要"活"。例如"阳光穿过树叶的阴影在地面上晃动""霓虹灯在雨水的倒影中闪烁变色"

另外，目前的视频模型对物理规律（重力、碰撞、液体流动）的理解仍在演进中。在 Prompt 里写明物理细节，能帮它更好地模拟：

- **温度与材质反应**："冰淇淋在烈日下慢慢化成液体，滴落在桌面上"；
- **节奏速度控制**：用 Slow motion（慢动作）、Timelapse（延时摄影）、High-speed camera（高速相机）来控制时间流逝的速度。

示例：

> **示例 PROMPT：**
>
> 一镜到底的电影级跟拍镜头，跟随一辆红色跑车在日落时分的沿海山路急转弯处漂移。轮胎激起烟雾，金色阳光在抛光的金属车身上闪烁，远处的海浪拍打着悬崖。高速动作摄影、动态运动模糊、4K、真实物理效果。

## 一张表看懂三者差异

| 维度 | 文生文 | 文生图 | 文生视频 |
|------|--------|--------|----------|
| 底层逻辑 | 语义关联、逻辑推理、符号变换 | 标签匹配、噪声去噪、空间构图 | 空间构图 + 时间轴帧间一致性 |
| 核心语言 | 逻辑词、限定词、步骤指引、示例 | 视觉名词、形容词、光影与艺术风格 | 动词（动作）、运镜词、时间控制、物理状态 |
| 最怕什么 | 模糊的概念（"写点好玩的"） | 因果逻辑（"因为……所以……"） | 复杂交互动作（"手穿过头发又拿出一支笔"） |
| 黄金公式 | 背景 + 任务 + 风格 + 约束 + 输出格式 | 主体 + 背景 + 构图 + 光影 + 风格 | 静态起幅 + 主体动作 + 运镜方式 + 节奏 |

掌握了这套逻辑，面对任何 AI 模型，你都能像一个经验丰富的"指令官"，用最契合它们底层架构的语言，精准拿到想要的结果。

## 从"会写"到"精通"：四个阶段

我自己一路练过来的路径，供你参考

深入掌握 Prompt，靠的不是死记硬背别人的"万能模板"——模型迭代太快了。2026 年的新一代大模型，对自然语言的理解力已经极高，很多复杂的结构化框架正在被弱化。

真正的高手，会把 Prompt 当成一门**"介于编程与心理学之间"的沟通技术**。

### 第一阶段：重塑底层思维，理解"为什么"

很多人的 Prompt 写不好，是因为把 AI 当成了"搜索引擎"或"真人"。想深入，先建立两个核心认知：

**一是概率预测思维。** AI 不是在"思考"你的问题，而是在根据你给的已知词（Tokens），预测下一个概率最高的词。所以要学会逆向思考：想要一个特定结果时，先问自己——"在互联网的海量公开文本中，什么样的前置条件，最容易引出我想要的答案？"上下文越精确，模型收敛到正确答案的概率就越高。

**二是注意力分配机制。** 大模型处理长文本时，对开头和结尾的信息最敏感，中间的内容容易被"遗忘"（即"大海捞针"现象）。所以排版是有讲究的：把最重要的指令、最严格的限制（如"只能输出 JSON"）放在 Prompt 最底部，背景资料放中间。

### 第二阶段：刻意练习，用好"控制变量法"

看十遍教程，不如自己去 Playground 做十次实验。最推荐的硬核练法，是做四轮对照实验。找一个固定的复杂任务，比如"让 AI 想 5 个小红书爆款标题"：

- **第 1 轮 · 零提示**：只给任务，看它输出什么
- **第 2 轮 · 加角色**：加上"你是一个拥有百万粉丝的母婴博主"，看用词风格的变化
- **第 3 轮 · 加示例**：给它两个你认为成功的标题作参考，看输出的格式和节奏
- **第 4 轮 · 加负面限制**：加上"不要出现'绝绝子''家人们'等高频词"

对比这四轮输出的差异，你会瞬间明白：**每一个 Prompt 维度，对模型底层到底产生了多大的扰动权重。**

日常用 AI 时，还可以练"多轮逼近法"：第一轮先给粗略方向，第二轮针对缺点校正（比如"第 2 点太官方了，用大白话重写，加一个生活中的小故事"），多轮打磨到满意后，把这几轮的精髓**压缩成一段话**——这就是一个高质量的单轮 Prompt。

### 第三阶段：进阶技巧的体系化学习

能熟练写出清晰指令后，去学三个进阶概念，这是把 Prompt 从"小技巧"上升为"工程学"的关键：

- **Meta-Prompting（元提示词）**：让 AI 帮你设计 Prompt。直接问它："我想要实现【具体任务】。为了让大模型完美执行这个任务，请你作为 Prompt 专家，为我设计一个结构严谨、带有示例和限制条件的最佳 Prompt。"
- **CoT（思维链）和 ToT（思维树）**：前者让模型写出思考步骤，对逻辑、数学、编程类任务胜率极高；后者让模型探索多条路径、自我辩论，适合决策类任务。
- **RAG（检索增强生成）适配**：学会给 AI 喂长篇文档，并要求它"只基于文档回答，不知道就说不知道"——这是目前企业落地最广的技术。

### 第四阶段：用好权威学习资源

- **官方 Playground 与 API 文档（最权威）**：别只在聊天窗口里玩，去 OpenAI 或 Anthropic 的开发者平台，那里可以调 Temperature（随机性）和 Top P。亲手体会一下：Temperature 调到 0（极其严谨、答案固定）和调到 1（极具创意、但容易胡说八道）时，你的 Prompt 应该分别怎么调整。海外的好搞，也可以尝试使用国内模型的 API，也是可以条件参数的
- **《ChatGPT Prompt Engineering for Developers》**：吴恩达联合 OpenAI 官方推出的短课。虽然有些年头，但关于"分隔符""系统提示"的底层逻辑，至今仍是金科玉律。
- **Learn Prompting（learnprompting.org）**：从零基础到高级工程的开源线性教程，图文并茂。
- **大厂官方指南**：Anthropic 的 Prompt Library、OpenAI 的 Prompt Engineering Guide。官方文档里的示例，都是经过成千上万次测试沉淀下来的标准格式。

## 写在最后

最好的 Prompt 学习状态，是三重视角的切换：

1. 像对程序员一样，给它清晰的边界与逻辑
2. 像对演员一样，给它明确的剧本与人设
3. 像对实习生一样，给它具体的参考样例

把这三句话记在心里。下次打开任何一个 AI 产品，你写下的第一句话，就已经领先大多数人了。
